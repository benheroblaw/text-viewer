    added CONFIG>
        did you hate having to add NOBR> to line after line? well, here's your solution!
            the only config command so far is "CONFIG>keep_whitespace", and as explained by its name, it respects your empty lines after the first non-DEF> and non-CONFIG> line!

    CONFIG>s will be used if they are in definition files

v0.2 - a bunch of shit
    added a background color for each color
        it's as simple as changing the first part of the color code from "38" to "48"
            this thing used to use the default terminal colors, but that's boring, so I switched it to a full 255 rgb.
            (it doesn't allow you to use all of those yet) (fuck i got an idea)
            the fun thing about that is: background and foreground colors use the exact same sequence!
            foreground color codes are "38:5:{color}m"
            background color codes are "48:5:{color}m"

    added orange
        that's it, i added the color orange
        background and foreground

    added defs? i think?
        you can label a series of format codes with one name to use later
        you can also make a .def or .defs file with a bunch of those for modularity :3
            these are called definition files!
